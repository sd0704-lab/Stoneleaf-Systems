# Stoneleaf Systems

> Enterprise IT Infrastructure Homelab & Professional Portfolio

## Overview

**Stoneleaf Systems** is a simulated enterprise IT environment designed to provide hands-on experience with the technologies, processes, documentation, and operational practices used by real-world IT departments.

The environment is built as more than a collection of disconnected labs. Stoneleaf Systems operates as a fictional organization with users, departments, servers, workstations, networking infrastructure, cloud resources, security controls, help desk operations, administrative tasks, change management, and ongoing IT projects.

This repository documents the complete design, deployment, administration, troubleshooting, security, and evolution of the environment.

---

## Project Goals

The primary goals of Stoneleaf Systems are to:

* Build and administer a realistic enterprise IT environment.
* Develop practical systems administration experience.
* Configure and manage Windows Server and Active Directory.
* Design and troubleshoot enterprise networking.
* Administer Windows and Linux systems.
* Implement virtualization and cloud infrastructure.
* Practice Microsoft Azure administration.
* Develop PowerShell and automation skills.
* Implement security controls and system hardening.
* Configure monitoring, logging, backup, and recovery.
* Operate a simulated help desk and ticketing environment.
* Practice change management and technical documentation.
* Troubleshoot realistic infrastructure failures.
* Document projects using professional IT standards.
* Build a portfolio demonstrating practical IT experience.

## Lab Methodology

Stoneleaf Systems will be developed incrementally.

Each major implementation will generally follow the same process:

1. Define the business requirement.
2. Define the technical requirement.
3. Design the solution.
4. Create a change request when appropriate.
5. Implement the configuration.
6. Test functionality.
7. Troubleshoot issues.
8. Validate security and operational requirements.
9. Document the final configuration.
10. Capture portfolio evidence.

This approach is intended to simulate how infrastructure work is performed within an actual IT organization rather than simply documenting successful configurations.
